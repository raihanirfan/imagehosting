◀ ImgOF API REST API v1

Overview

ImgOF provides a lightweight REST API for automated image uploading, metadata retrieval, and deletion. No API key is required for public usage (rate-limited to 30 requests/min).

Base URL: https://imgof.my.id/api
POST

/api/upload

Upload a single image file via multipart/form-data.

cURL Example: 
curl -X POST https://imgof.my.id/api/upload \
  -F "file=@/path/to/image.png"
Python (requests): 
import requests

url = "https://imgof.my.id/api/upload"
with open("screenshot.png", "rb") as f:
    response = requests.post(url, files={"file": f})
    data = response.json()
    print(data["url"])
JSON Response (201 Created): 
{
  "success": true,
  "id": "a1b2c3",
  "url": "https://imgof.my.id/i/a1b2c3.png",

POST

/api/upload (Remote URL)

Fetch and store an image from a public remote URL via JSON body.

cURL Example: 
curl -X POST https://imgof.my.id/api/upload \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.com/sample.jpg"}'
DELETE

/api/delete/:id?token=...

Permanently delete an image using its unique delete token.

curl -X DELETE "https://imgof.my.id/api/delete/a1b2c3?token=YOUR_DELETE_TOKEN"
GET

/api/info/:id

Retrieve public metadata for an image (view counts, size, creation date).

curl https://imgof.my.id/api/info/a1b2c3
