Tentang ImgOF

Fast, anonymous image hosting — tanpa akun.

ImgOF adalah tempat titip gambar paling simpel: drag, upload, copy link. Tanpa daftar, tanpa iklan tracking, langsung lewat CDN global.

Kenapa ImgOF

⚡
Cepat & ringan

Serverless di Cloudflare Workers + R2. Upload 10MB sekejap, hotlink tanpa watermark.

🔒
Anonim

Tanpa akun. Hapus kapan saja pakai Delete Token. EXIF GPS otomatis di-strip.

🛡️
Aman

Rate-limit, SSRF guard, hash+AES IP, backup Drive & Pixeldrain di belakang.

Cara pakai

  1. Drag & drop atau paste gambar (JPG/PNG/WebP/GIF/SVG, max 10MB).
  2. Copy link — Direct, Markdown, HTML, atau BBCode.
  3. Simpan Delete URL/Token untuk hapus nanti. Lihat semua di My Gallery.

Teknologi

ImgOF jalan di Cloudflare Workers + R2 untuk CDN, D1 untuk metadata, dan cadangan ke Google Drive (/24 sharded) + Pixeldrain/Buzzheavier. Gak ada server yang perlu di-maintain — scale otomatis.

Batasan

Bukan backup permanen — selalu simpan file asli di lokal. Lihat Legal untuk larangan CSAM/malware/NCII dan DMCA 3–5 hari.
